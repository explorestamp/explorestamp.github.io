## 打卡範圍

在景點現場按下「蓋章打卡」時，App 會確認你與景點的距離。各分類的預設範圍如下，佔地較大的景點（例如夜市、藝術特區）另有個別設定。

| 分類 | 打卡範圍 |
| --- | --- |
| 機場 | 1000 公尺 |
| 主題樂園、自然景點 | 500 公尺 |
| 動物園與水族館、大學校園、觀光工廠 | 400 公尺 |
| 博物館、美術館、表演與運動場館、地標與觀景台、古蹟、宗教聖地、購物與商圈 | 300 公尺 |
| 市集、夜市、鐵道車站 | 250 公尺 |
| 圖書館 | 200 公尺 |
| 書店、美食、咖啡廳 | 150 公尺 |
